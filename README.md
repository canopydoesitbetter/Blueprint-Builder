# Blueprint Builder

Standalone Blueprint Builder prototype extracted from Fabri-Cadabra for independent development.

## Current prototype

- Shared X/Y/Z tube model
- Top plus Wall A/B/C/D synchronized 2D projections
- Rotate Right sequence: A → B → C → D → A
- Approved shared-edge orientation
- 2×2, 3×3, and 2×6 tubing
- Tube lengths entered and displayed in inches only
- Quantity staging and return on delete
- Grid/object snapping
- Zoom, pan, and Fit controls

## Direction

The next UI pass is a true mobile-first rebuild. The current geometry/model work is being preserved while the interface is redesigned around a phone-first canvas, bottom sheets, touch placement, pinch zoom, and compact view controls.

This repository is intentionally separate from the production Fabri-Cadabra application.
